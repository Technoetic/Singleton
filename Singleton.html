📚 Singleton 패턴 설명

패턴 개요

Singleton 패턴은 클래스의 인스턴스가 오직 하나만 생성되도록 보장하는 생성 패턴입니다. 전역 접근점을 제공하면서도 인스턴스 생성을 제어합니다.

핵심 특징

• 단일 인스턴스 보장
• 전역 접근점 제공
• 지연 초기화 가능
• 스레드 안전성 고려 필요

적용 사례

• 데이터베이스 연결 관리
• 로깅 시스템
• 설정 관리자
• 테마 관리자 ← 현재 예제

💻 구현 코드

class ThemeManager { // 1. private static 인스턴스 변수 static #instance = null; // 2. private 생성자 - 외부에서 직접 생성 불가 constructor() { if (ThemeManager.#instance) { throw new Error('ThemeManager는 Singleton입니다. getInstance()를 사용하세요.'); } this.currentTheme = 'light'; this.instanceId = Math.random().toString(36).substr(2, 9); this.themeChangeListeners = []; ThemeManager.#instance = this; } // 3. public static 메서드로 인스턴스 접근 static getInstance() { if (!ThemeManager.#instance) { ThemeManager.#instance = new ThemeManager(); } return ThemeManager.#instance; } // 테마 변경 메서드 setTheme(theme) { this.currentTheme = theme; this.notifyListeners(); } getTheme() { return this.currentTheme; } // 옵저버 패턴: 테마 변경 알림 subscribe(callback) { this.themeChangeListeners.push(callback); } notifyListeners() { this.themeChangeListeners.forEach(cb => cb(this.currentTheme)); } }
